# Verascope — Fake News Detection System

A simple, self-contained **Python + Flask + HTML/CSS/JS** project that predicts
whether a piece of news text is **REAL** or **FAKE**, using TF-IDF + Logistic
Regression. No separate frontend framework required — Flask serves the HTML
directly, which keeps the project easy to run and easy to explain in a viva.

## Project structure

```text
fake-news-detection/
├── app.py                  # Flask app: routes + /predict API
├── train_model.py          # Loads dataset, trains & saves the model
├── requirements.txt
├── model.pkl                # generated by train_model.py
├── vectorizer.pkl           # generated by train_model.py
├── dataset/
│   ├── generate_dataset.py  # creates a small synthetic dataset (demo only)
│   ├── Fake.csv
│   └── True.csv
├── templates/
│   ├── base.html
│   ├── index.html           # home page + analyzer tool
│   └── about.html
└── static/
    ├── style.css
    └── app.js
```

## About the dataset

`dataset/Fake.csv` and `dataset/True.csv` were generated by
`dataset/generate_dataset.py` as a small **synthetic** dataset, purely so the
project trains and runs end-to-end out of the box.

**For a real submission, replace these two files with a genuine dataset**
(for example, search "Fake and Real News Dataset Kaggle" — it ships as
`Fake.csv` / `True.csv` with a `text` column). Keep the column named `text`
and everything else works unchanged. Then re-run `train_model.py`.

## Setup

1. **Create a virtual environment (recommended)**

   ```bash
   python -m venv venv
   source venv/bin/activate      # Windows: venv\Scripts\activate
   ```

2. **Install dependencies**

   ```bash
   pip install -r requirements.txt
   ```

3. **Train the model** (creates `model.pkl` and `vectorizer.pkl`)

   ```bash
   python train_model.py
   ```

   You should see a test accuracy and classification report printed —
   that's the model checking itself on data it didn't train on.

4. **Run the app**

   ```bash
   python app.py
   ```

   Then open **http://127.0.0.1:5000** in your browser.

## How to use it

- Go to the home page, paste a headline or a few sentences into the box.
- Click **Analyze** (or press Ctrl/Cmd + Enter).
- You'll get a **REAL NEWS** / **FAKE NEWS** label with a confidence
  percentage, plus a short explanation.
- **Try an example** fills in a sample headline if you want a quick demo.
- Your last few checks appear under **This session** (not saved anywhere —
  it resets on page reload).
- Visit **How it works** for a plain-language explanation of NLP, TF-IDF,
  and Logistic Regression, suitable for a viva.

## API

### `POST /predict`

Request:

```json
{ "text": "News article content entered by the user" }
```

Response:

```json
{ "prediction": "FAKE", "confidence": 94.5 }
```

Errors (e.g. missing/too-short text) return a 4xx status with:

```json
{ "error": "explanation of what went wrong" }
```

### `GET /health`

Returns `200` with `{"status": "ok", ...}` if the model loaded correctly,
or `503` with an explanation if it didn't (usually meaning
`train_model.py` hasn't been run yet).

## Notes for the viva

- **Cleaning**: `clean_text()` in `train_model.py` and `app.py` does the
  exact same steps (lowercase, strip URLs/HTML/punctuation/digits) — this
  consistency matters, since the model must see text preprocessed the same
  way at prediction time as it did during training.
- **TF-IDF**: converts cleaned text into a sparse numeric matrix, capped at
  5000 features, with English stop words removed.
- **Logistic Regression**: a simple, fast, interpretable linear classifier —
  a sensible baseline for binary text classification, and easy to explain
  (it outputs a probability, which becomes the confidence score).
- **Confidence score**: taken directly from `model.predict_proba()`, i.e.
  the model's own probability estimate for its chosen label.
